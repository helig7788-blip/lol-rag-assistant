# 不祥之刃（卡特琳娜）

## 背景故事
果断坚决、心狠手辣，卡特琳娜是诺克萨斯的顶尖刺客。作为传奇将军杜·克卡奥的长女，她凭借出其不意的迅猛刺杀很快声名鹊起。强烈的野心曾经驱使她挑战重兵把守的暗杀目标，甚至不惜冒险让友军暴露在危险中。不过无论是怎样的任务，卡特琳娜都会毫不迟疑地在锯刃匕首的风暴中履行自己的使命。

## 基础属性
生命值: 672
攻击力: 58
护甲: 32

## 被动技能：贪婪
每当一名在过去3秒被卡特琳娜所伤害的敌方英雄阵亡时，卡特琳娜的技能的冷却时间就会显著减少。<br><br>如果卡特琳娜拾起一把<font color='#FFF673'>匕首</font>，她会用它来斩击附近的所有敌人以造成魔法伤害。

## 弹射之刃
卡特琳娜朝敌人扔出一把<font color='#FFF673'>匕首</font>，<font color='#FFF673'>匕首</font>会弹射到附近敌人身上，然后落到地面上。

## 伺机待发
卡特琳娜获得爆发性的移动速度加成，同时投掷一把<font color='#FFF673'>匕首</font>到她正上方的空中。

## 瞬步
卡特琳娜立刻闪烁到目标处，如果目标是敌人，则她会对目标造成伤害，否则会对距她最近的敌人造成伤害。

## 死亡莲华
卡特琳娜化身为一道剑刃飓风，以无与伦比的速度对周围最多三个敌方英雄造成巨量魔法伤害。
