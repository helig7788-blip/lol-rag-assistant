# 涤魂圣枪（赛娜）

## 背景故事
自幼便遭遇诅咒的赛娜，注定会被那些超自然的诡秘黑雾不断侵扰，后来她加入了神圣的“光明哨兵”教团，对黑雾发起了勇猛的反击。可惜，最后她却牺牲在战场上，灵魂则被囚禁在残忍的亡灵——锤石的灯笼中。身陷囹圄的赛娜并没有放弃希望，而是学会了利用黑雾的力量，把握机会重获新生，也因此被永远地改变了。如今的赛娜可以同时操纵黑暗和光明的力量，动用黑雾的力量来终结黑雾——圣石武器的每一发炮火，都能救赎黑雾中迷失的灵魂。

## 基础属性
生命值: 530
攻击力: 50
护甲: 25

## 被动技能：赦除
当赛娜附近有单位死亡时，这些单位的灵魂会周期性地被黑雾所捕获。赛娜可以攻击这些灵魂来解脱他们，并吸收使他们困在死界的黑雾。黑雾会为她的圣枪提供燃料，提升她的攻击力、攻击距离和暴击几率。<br><br>赛娜的圣物火炮需要更长的射击时间，造成额外伤害，并暂时为她提供她目标的一部分移动速度。

## 黑暗洞灭
赛娜从她的圣物火炮的双生炮管中射出一道光影相生之芒来洞穿一个目标，治疗友军并伤害敌人。

## 无尽厮守
赛娜向前发射一道黑雾。如果它命中了一名敌人，它就会饥渴地纠缠住该敌人，在短暂的延迟后对该敌人及其附近的单位造成禁锢效果。

## 黑雾咒附
赛娜将她存在武器内的黑雾抽出，在她四周形成一团风暴，然后投身于黑暗并变成幽魂。进入黑雾区域的友军会变成伪装状态，并且在被黑雾笼罩时也会呈现出幽灵的外观。幽魂会获得移动速度提升，无法被选中，并且隐藏自身的身份。

## 暗影燎原
赛娜召唤陨落哨兵们的圣石，将她的圣物火炮拆分成一座光与影的神圣阵列。她随后会发射一道不限距离的光束，来为命中的友军提供护盾，并对中心区域内的敌人造成伤害。
