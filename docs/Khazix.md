# 虚空掠夺者（卡兹克）

## 背景故事
虚空在成长，虚空在进化——在众多虚空生物中，没有谁能比卡兹克更完美体现这一特性。进化让这种恐怖的能力不断变异，求生的本能让它不断弑杀强者，只要遇到障碍，它就会进化出新的、更有效的方法反杀猎物。最初卡兹克只是一头愚钝的野兽，但随着智力与形态的不断进化，现在它已学会了提前计划狩猎行动，甚至懂得在猎物心中制造最真实的恐惧。

## 基础属性
生命值: 643
攻击力: 60
护甲: 32

## 被动技能：无形威胁
附近陷入<font color='#FFF673'>孤立无援</font>状态的敌人会被标记出来。卡兹克的技能会与<font color='#FFF673'>孤立无援</font>的目标产生交互作用。<br><br>当卡兹克没有被敌方队伍所看见时，他会获得无形威胁，使他的下次对敌方英雄发动的普通攻击造成额外魔法伤害，并使目标减速数秒。

## 品尝恐惧
对目标造成物理伤害。对<font color='#FFF673'>孤立无援</font>的目标造成的伤害会提高。如果他选择<font color='#00DD33'>进化收割利爪</font>的话，这个技能会在对抗<font color='#FFF673'>孤立无援</font>的目标时返还一部分冷却时间。卡兹克也会提升他的普通攻击和品尝恐惧的距离。

## 虚空突刺
卡兹克发射爆炸性的尖刺，对命中的敌人造成物理伤害。卡兹克如果在爆炸范围内，则会回复生命值。如果他选择<font color='#00DD33'>进化刺鞘</font>的话，虚空突刺现在会呈锥形发射三个尖刺，减速被命中的敌人并使被命中的敌方英雄显形2秒。<font color='#FFF673'>孤立无援</font>的目标会被减速额外的幅度。

## 跃击
卡兹克跳向一个区域，在着陆时造成物理伤害。如果他选择<font color='#00DD33'>进化虫翼</font>的话，跃击的距离会提升200并在击杀和助攻时重置冷却时间。

## 虚空来袭
每升一级此技能都会允许卡兹克进化他的一项技能，给予该技能独特的附加效果。在激活【虚空来袭】时，会使卡兹克变成<font color='#91d7ee'>隐形</font>状态，触发无形威胁并提升移动速度。如果他选择<font color='#00DD33'>进化动态遮蔽</font>的话，【虚空来袭】获得已提升的<font color='#91d7ee'>隐形</font>持续时间，以及一次额外的使用次数。
