# 河流之王（塔姆）

## 背景故事
塔姆在历史上有许多不同的名字，他游历于符文之地的各条水道，用大意之人的悲惨喂养自己贪得无厌的食欲。虽然他的外表可能富有古怪的魅力和得意，但他在物质领域的漫游只是为了寻找毫无戒心的猎物。他的舌头像巨大的鞭子，即使是全副武装的重甲士兵也会被他从十几步以外的距离击晕，而如果跌入了他隆隆作响的肚子里，就相当于掉进了九死一生的绝命深渊。

## 基础属性

## 被动技能：培养品味
塔姆将他那庞大身躯的分量夹杂在他的攻击和技能中，从而使他能造成基于自身总生命值的额外伤害。对敌方英雄造成伤害时，塔姆可以在目标身上叠加<spellName>培养品味</spellName>的层数。当敌方英雄身上的层数到达3时，塔姆可以使用<spellName>大快朵颐</spellName>来吞噬这名敌方英雄。

## 巨舌鞭笞
塔姆用他的舌头进行猛击，对命中的第一个单位造成伤害和减速效果并在他命中一名敌方英雄时治疗自身。<br><br>对敌方英雄施加一层<spellName>培养品味</spellName>效果。如果目标英雄已经被叠加了3层<spellName>培养品味</spellName>，那么该英雄还会被晕眩，并且层数会被消耗掉。

## 深渊潜航
下潜然后重新出现在目标位置，对一个区域内的所有敌人造成魔法伤害和击飞效果。

## 厚实表皮
<passive>被动：</passive>塔姆将他所受的一部分伤害储存起来，并在脱离战斗后基于已储存的伤害值来治疗自身。<br><br><active>主动：</active>将所有已储存的伤害值转化为一个临时的护盾。

## 大快朵颐
塔姆吞噬一名英雄若干秒，如果该英雄是敌人则对其造成魔法伤害，如果该英雄是队友则为其提供护盾。
