# 双界灵兔（阿萝拉）

## 背景故事
从诞生那一刻起，阿萝拉就能够在精神和物质领域之间游走；长大后，她决定细细探索精神领域的生物，于是远走他乡，寻觅未知。机缘巧合间，她遇见了一位迷失的半神，他在漫漫岁月中被遗忘，变得痛苦扭曲。此等绝望，阿萝拉无法坐视不管，她要帮这位狂野不羁的朋友找回他原本的身份，于是踏上了一段遍迹弗雷尔卓德的探寻之旅。

## 基础属性
生命值: 607
攻击力: 53
护甲: 23

## 被动技能：驱灵奇术
阿萝拉的技能或攻击伤害能从敌人身上抽离出灵物。被抽离灵物跟随阿萝拉并治疗她。

## 飞去来咒
阿萝拉放出一道飞弹，诅咒所有命中的敌人。阿萝拉可以再次施放该技能，来将所有激活的诅咒抽回自己身上。诅咒在返回途中会对命中的敌人造成伤害。

## 灵纱洞开
阿萝拉跳向选定方向，并在落地时进入精神领域，在短时间内进入隐形状态并获得移动速度。

## 怪奇喷涌
阿萝拉打开界域之窗，施放出一道灵魂魔法洪流，让双界汇聚，放出一道灵物魔法震波，对敌人造成伤害和减速，然后阿萝拉也会向后跳到安全处。

## 双界合一
阿萝拉跳向选定方向，释放出一片灵冲击波，对命中的敌人造成伤害和减速。然后，她会创造一个区域来减速其中的敌人们，并且允许阿萝拉从该区域的一侧传送到另一侧。
