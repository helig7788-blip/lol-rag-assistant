# 奥术先驱（维克托）

## 背景故事
完成了生物机械进化的维克托，已经彻底实现了自己的光荣进化，成为了追随者们心中的救世主。他坚信抹去情感即可终结一切痛苦，为了实现这一目标，他牺牲了自己的人性。如今，他希望将海克斯核心推广到世界各个角落，就算世人无法理解其中的好处，他也势在必行。毕竟，对这名奥术之主来说，暴力只是这道终极公式中一个不可或缺的变量。

## 基础属性
生命值: 600
攻击力: 53
护甲: 23

## 被动技能：光荣进化
维克托会在击杀一名敌人后获得海克斯碎片。每获得100个海克斯碎片，维克托将永久强化一个主动技能。升级完所有基础技能后，他可以再收集100个海克斯碎片，用来强化自己的终极技能。

## 虹吸能量
维克托引爆一个敌方单位，造成魔法伤害，同时获得一道护盾，并强化自己的下次普通攻击。<br><br>增强：虹吸能量的护盾提升60%，并且维克托在施放这个技能后获得额外移动速度加成。<br>

## 重力场
维克托放出一个重型引力场装置，使半径范围内的敌人减速。在力场中驻留时间过长的敌人会遭到晕眩。<br><br>增强：维克托的技能会对命中的敌人施加一个减速效果。<br>

## 海克斯射线
维克托用自己的生物机械臂发射一束海克斯射线，沿一条直线在战场上切割，对沿途敌人造成伤害。<br><br>增强：一道爆炸会跟随海克斯射线的轨迹，造成魔法伤害。<br>

## 奥术风暴
维克托在场上召唤一道奥术风暴，对敌人造成魔法伤害并打断敌人的引导。之后风暴会周期性对附近所有敌人造成魔法伤害，且可以被维克托重新导向。<br><br>增强：奥术风暴的移动速度提升25%，每有英雄在受到风暴伤害后阵亡，风暴就会扩大，持续时间也会延长。<br><br>
