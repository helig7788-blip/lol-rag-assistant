# 纳祖芒荣耀（奎桑提）

## 背景故事
威武不屈的奎桑提，与山峦般的巨兽和残忍的飞升者不懈地战斗，只为保护自己的家园纳祖芒——恕瑞玛沙漠中一处明珠般的绿洲。但自从与曾经的伙伴分别，奎桑提意识到他要是渴望成为一名足够领导纳祖芒的英雄，就必须克服自己一心求胜的固执。只有这样，他才不会被自己的傲慢所吞噬，最终收获他所需的智慧，击溃那些足以威胁族人的恐怖对手。

## 基础属性
生命值: 625
攻击力: 64
护甲: 36

## 被动技能：血性本能
奎桑提的技能会标记目标来使他的下一次攻击对其造成更多伤害。<br><br>在全盛姿态下，奎桑提的所有攻击和技能造成更多伤害。

## 无双陀斧
奎桑提进行打击，对一条较短直线内的所有敌人造成伤害和减速效果。<br><br>命中敌人时会提供一层【无双陀斧】。在2层时，奎桑提会发射一道可将敌人拉近的冲击波。<br><br>在全盛姿态下，冷却时间会缩短。

## 辟路先锋
奎桑提进行蓄力，期间获得伤害减免，然后进行冲刺，对敌人造成击退和晕眩。<br><br>在全盛姿态下，造成提升过的伤害并且不再造成击退或晕眩。

## 大步驰援
奎桑提进行冲刺并获得一个护盾。如果以一个友军为目标，则奎桑提的冲刺距离会提升并冲刺至该友军处，两人都会获得一个护盾。<br><br>在全盛姿态下，冷却时间会缩短，并且速度会提升。

## 傲岸雄姿
奎桑提将一个敌人击退，并带其翻越沿途的任何墙体。然后，奎桑提进入【全盛姿态】并冲刺至其身后，获得提升过的伤害、治疗效果、以及转化过的各个技能，但代价是各防御属性降低。
