# 战争之影（赫卡里姆）

## 背景故事
赫卡里姆是人与兽的幽灵混合体，身上的诅咒让他只能永世不停地践踏生者的灵魂。在福光岛被暗影吞噬之际，这位高傲的骑士被破败之咒的毁灭能量彻底湮没——连同他的骑兵团和他们胯下的坐骑。现在，符文之地上只要是有黑雾出现的地方，就会有赫卡里姆率军冲锋的鬼影，他们肆虐雀跃，用铁蹄践踏着脚下的幽魂。

## 基础属性
生命值: 625
攻击力: 66
护甲: 32

## 被动技能：征战之路
赫卡里姆获得相当于他一部分额外移动速度的攻击力加成。

## 暴走
赫卡里姆猛劈周围的敌人，同时造成物理伤害。如果这个技能对至少一名敌人造成伤害，那么赫卡里姆会提升【暴走】的伤害并为随后施放的【暴走】缩短冷却时间。

## 恐惧之灵
赫卡里姆获得护甲和魔抗。赫卡里姆对附近敌人造成魔法伤害，并基于敌人所受的伤害来恢复生命值。

## 毁灭冲锋
赫卡里姆获得不断提升的移动速度加成并且移动时可以无视单位的碰撞体积。他的下一次攻击将会击退目标，并且造成额外物理伤害，伤害值基于他在激活该技能后所移动的距离。

## 暗影冲击
赫卡里姆召唤幽魂骑兵向前冲锋，对一条直线上的敌人造成魔法伤害。赫卡里姆会在完成他的冲锋时发出一道冲击波，来使周围的敌人惊慌失措地逃命。
